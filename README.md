# Сезонка — интерактивная книга меню

Статическая веб-книга: три недели меню, 63 карточки блюд, масштабирование ингредиентов и покупок на 1–4 человек, сохраняемый чек-лист и блоки заготовок.

## Запуск

Откройте `index.html` локально или опубликуйте как статический сайт. Фотографии обложки и блюд лежат в корне репозитория.

Исходная книга меню: [Google Docs](https://docs.google.com/document/d/1brnrde3rNVIUT6kxHXx_zEGTDvTQ0zEyNRZIvsrwSPQ/edit).

## Редактирование

- `menu-data.js` — меню, ингредиенты, рецепты, покупки и заготовки.
- `index.html`, `styles.css` и `app.js` — структура, оформление и интерактивность.
- `assets/` — изображения.

Для GitHub Pages опубликуйте корень ветки `main`. Сборка и установка зависимостей не требуются.
