# Сезонка — интерактивная книга меню

Предпросмотр первой недели статической веб-книги: 21 карточка блюд, масштабирование ингредиентов и покупок на 1–4 человек, сохраняемый чек-лист и блоки заготовок.

Ветка `week-1-preview` содержит только рабочую первую неделю. Вторая и третья недели отмечены серым как «Будет доступно позже».

## Запуск

Откройте `index.html` локально или опубликуйте как статический сайт. Изображения находятся в `assets/`.

Исходная книга меню: [Google Docs](https://docs.google.com/document/d/1brnrde3rNVIUT6kxHXx_zEGTDvTQ0zEyNRZIvsrwSPQ/edit).

## Редактирование

- `menu-data.js` — меню, ингредиенты, рецепты, покупки и заготовки.
- `index.html`, `styles.css` и `app.js` — структура, оформление и интерактивность.
- `cover.jpg`, `cod.jpg`, `chicken.jpg` и `meal-day*.png` — фотографии блюд. Логотип встроен в страницу.

Для GitHub Pages опубликуйте корень ветки `main`. Сборка и установка зависимостей не требуются.
